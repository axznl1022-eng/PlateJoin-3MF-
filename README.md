# PlateJoin-3MF-
PlateJoin（3MF 拼盘助手）是一款轻量级 Windows 工具，可将多个拓竹 3MF 项目合到同一块打印板，尽量保留各模型的打印设置，支持参数对比和本地试切片。  PlateJoin is a lightweight Windows tool that merges Bambu Studio 3MF projects onto one build plate. It preserves supported per-model settings and lets you compare settings and run a local test slice.
